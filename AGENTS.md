# Правила работы над PricePilot

## Назначение
PricePilot — отдельный продукт для закупок. Не добавляйте в него сценарии EstimateCheck. Общий DIP разрешён только как платформенный слой Document Intelligence Engine и переиспользуемые технические компоненты.

## Зафиксированные границы
- Desktop: Tauri 2, React, TypeScript. Backend: FastAPI/Python.
- Модульный монолит с явными границами доменных модулей.
- SQLite локально; PostgreSQL для облака. Репозитории и миграции скрывают различия движков.
- Local-first, оригиналы остаются локально по умолчанию. Любая передача в cloud AI требует явного согласия на конкретный файл/операцию.
- Не маркируйте неподдерживаемый или неуспешно разобранный файл как обработанный.
- Не перезаписывайте оригиналы. Не теряйте источник, страницу, координаты, строку или уверенность для извлечённых данных.
- Пользователь подтверждает сомнительные сопоставления, единичные преобразования, валютные и стоимостные предположения.

## Инженерные правила
- TypeScript strict; Python типизирован, форматируется и проверяется статическими анализаторами.
- Доменные правила не размещать в UI, HTTP-роутерах или ORM-моделях.
- Денежные величины хранить как Decimal/fixed precision, не float. Валюта обязательна.
- Все даты — ISO 8601 с часовым поясом, если это момент времени; даты документа — отдельный тип.
- Миграции обязательны; не изменять рабочие схемы вручную.
- API версионируется; ошибки имеют стабильный code и correlation_id.
- Логи не должны содержать полные документы, секреты и лишние персональные данные.
- Любое внешнее/AI-значение сохраняет происхождение, метод и статус проверки.
- Уважать локальный режим: базовый workflow должен работать без аккаунта и сети.

## Изменения и проверка
Перед изменением изучите соседние модули и сохраните существующие пользовательские решения. Добавляйте тесты к доменной логике, форматтерам, миграциям и парсерам. Для каждого поддерживаемого формата проверяйте корректный файл, повреждённый файл и превышение лимита. Обновляйте документацию контрактов при изменении API или схемы.
