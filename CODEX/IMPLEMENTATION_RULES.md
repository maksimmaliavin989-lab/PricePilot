# Правила реализации для Codex

- Прежде чем выбирать библиотеки, проверь лицензию, сопровождение и возможность офлайн-упаковки.
- Не менять принятый стек без ADR и основания.
- Не отправлять файлы/текст внешнему API без отдельного явного consent flow.
- Парсеры изолировать, ограничивать по ресурсам, не выполнять макросы/формулы.
- Числа прайсов неоднозначны: `1,234`/`1.234` и разделители тысяч должны попадать на review, если формат не задаёт локаль.
- Сохранять raw, normalized и provenance раздельно.
- Matching — подсказка с объяснением; не сливать товар без заданной политики.
- Формула landed cost — версионируемый доменный сервис; никакой налоговой ставки по умолчанию без подтверждённого источника.
- Экспортировать CSV/XLSX с защитой от formula injection; метаданные provenance включать.
- Изменения schema/API сопровождаются миграцией/контрактом.
