# Стартовая точка для Codex

1. Прочитай корневой `AGENTS.md`, README и техническое задание.
2. Начинай с `CODEX/TASKS/TASK_001_FOUNDATION.md`; выполняй один законченный вертикальный срез за раз.
3. До изменений зафиксируй структуру существующего репозитория и реальные доступные зависимости; не предполагай, что проект пуст.
4. Если неопределённость влияет на безопасность, данные или коммерческую формулу — зафиксируй вопрос как открытое решение, не выдумывай ответ.
5. После реализации сообщи изменённые файлы, команды проверки и известные ограничения.

Локальный desktop MVP PricePilot на Tauri 2 + React/TS + FastAPI. Платформенный DIP Document Engine можно развивать независимо через интерфейсы. Cloud и EstimateCheck не добавлять без отдельного требования.
