# TASK 005 — Desktop packaging и безопасный runtime

Собрать Tauri 2 desktop shell с FastAPI sidecar, bundled Python/runtime и локальными OCR resources. Определить startup, shutdown, crash recovery, migration prompt, app data path и backup/restore. Минимизировать Tauri capabilities, CSP и сетевые origins. Подготовить Windows/macOS package pipeline и подпись как release-stage requirement.

**Приёмка:** запуск/выход/повторный запуск, отсутствие сети, sidecar crash recovery, порт только loopback, чистая установка и upgrade без потери локальных данных.

**Обязательные явные проверки** (добавлены после TASK_004, где webview проверялся только в браузере, а офлайн — только по списку запросов):
1. **Окно Tauri, собранное приложение.** В окне упакованного приложения (не dev-браузер) пройти US-01/US-02: импорт CSV/XLSX, очередь, открытие проверки, панель оригинала, исправление поля с причиной, подтверждение/отклонение цен; закрыть и открыть приложение — правки на месте.
2. **Без сети на уровне процессов.** Запустить упакованное приложение в macOS sandbox, запрещающем любые исходящие соединения кроме `localhost`, и пройти тот же сценарий; зафиксировать, что попытка внешнего соединения из процесса действительно блокируется.
3. **Реально выключенный интернет.** С выключенным Wi‑Fi/сетью (переключает пользователь; агент системные настройки не меняет) подтвердить отсутствие интернета и пройти сценарий п. 1. Пока не выполнено — в отчёте указывать как непроверенное.
4. **Сбой sidecar.** Принудительно завершить процесс API — оболочка перезапускает его, UI восстанавливает соединение, данные целы.
5. **Upgrade.** База предыдущей версии схемы открывается новой сборкой: перед миграцией создаётся резервная копия, данные сохраняются.

**Изменение по ходу проверки:** опт/розница — это типы цен прайса, а не неоднозначность строки: при распознанных типах колонок строки больше не помечаются `MULTIPLE_PRICE_COLUMNS` (pipeline `dip-0.2.0`); выбор цены — задача сравнения (TASK_006).

Также проверено: выход оболочки не оставляет процессов API; повторный запуск поднимает API; второй экземпляр на том же каталоге данных отказывается стартовать (`ALREADY_RUNNING`). Windows-пакет и `release.yml` пока не запускались.
