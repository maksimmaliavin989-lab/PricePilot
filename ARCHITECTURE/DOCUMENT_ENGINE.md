# DIP Document Intelligence Engine

## Граница платформы
Общий DIP слой отвечает за приём и сохранение файла, определение формата, извлечение структуры, OCR/layout, происхождение данных, версии pipeline, статусы задач и нейтральный canonical document model. PricePilot отвечает за смысл прайс-листа: товар, предложение, упаковка, коммерческие условия, сопоставление и закупочный расчёт.

## Адаптеры форматов
- XLSX/XLS/CSV: листы, строки, столбцы, формулы/значения (фиксировать оба, когда доступны), merged cells.
- DOCX: таблицы и параграфы с порядком чтения; заголовки секций.
- PDF digital: текстовые блоки и координаты.
- PDF scanned, JPG/JPEG, PNG, TIFF: локальная OCR обработка, страницы/области, язык/поворот.
- DOC: неподдерживаемый бинарный формат до внедрения безопасного адаптера; ошибка явная.

## Pipeline
1. Intake: MIME sniffing по содержимому, лимиты, хэш, карантин, antivirus hook при наличии.
2. Classification: тип/страницы/таблицы и пригодность.
3. Parse: извлечение текста/таблиц.
4. OCR/Layout: локально; язык определяется или выбирается; блоки и bounding boxes.
5. Extraction: schema-guided извлечение полей; правила перед ML/LLM.
6. Validation: типы, диапазоны, арифметика, обязательные поля.
7. Canonicalization: source fields → канонические значения с confidence.
8. Review: человек принимает/правит; все исправления версионируются.

## Canonical provenance
Каждое поле имеет: `raw_value`, `normalized_value`, `source_document_id`, `page`, `sheet`, `cell`, `line/region`, `extractor`, `pipeline_version`, `confidence`, `review_status`, `reviewed_by`, `reviewed_at`. Для поля без координат указывается доступный ближайший источник и статус точности локализации.

## Политика AI
Cloud AI optional и opt-in per operation. До отправки — название провайдера, перечень данных, регион/цель/срок по доступным условиям и явная кнопка согласия. Передаваемый набор минимизируется. Ответ AI — предложение, никогда не подтверждённый факт. Отказ/недоступность облака не ломает локальный pipeline.
