# Критерии приёмки и Definition of Done

Функция принимается, когда:
1. Сценарии и крайние случаи описаны; UI/ошибки соответствуют фактической поддержке.
2. Доменные правила тестируются; миграция проверена; API контракт обновлён.
3. Provenance и audit сохранены для извлечения и исправления.
4. Денежная арифметика использует Decimal и имеет тесты округления/валюты/нулей.
5. Ошибка, отмена, повтор и перезапуск имеют определённое поведение.
6. Для файлов проверены лимиты, неверный MIME, повреждение и обработка без сети.
7. Нет непреднамеренной сетевой отправки; cloud AI gated явным consent.
8. Документация, release notes и ограничения актуальны.
9. Доступность проверена клавиатурой; важные статусы не передаются только цветом.

## MVP acceptance walkthrough
Создать workspace и поставщика → импортировать прайс → открыть строку в оригинале → поправить поле и сохранить источник → создать продукт и принять match → сравнить два предложения с разными упаковками/валютами → показать breakdown полной стоимости и предупреждения → экспортировать → закрыть и открыть приложение без сети и убедиться в сохранности.
