# Техническое задание PricePilot

## 1. Цель
Реализовать desktop-приложение закупок для импорта прайсов, проверки извлечения, ведения каталога, сопоставления позиций и сравнения полной стоимости.

## 2. Технологический baseline
Tauri 2; React + TypeScript strict; FastAPI/Python; SQLAlchemy/SQLModel или эквивалентный repository layer; Alembic migrations; SQLite local; PostgreSQL cloud; локальные парсеры/OCR через DIP Document Intelligence Engine. Выбор конкретных библиотек зафиксировать ADR с лицензией и оценкой безопасности.

## 3. Роли
Локальный владелец workspace; участник закупок; reviewer/manager. Для MVP single-user local допустим, но модель авторства должна поддерживать команды в cloud версии.

## 4. Основные сущности и потоки
Workspace → Supplier → SourceDocument → ProcessingRun → ExtractedLine/Field → Product/Offer → MatchDecision → Comparison → CostSnapshot → Export. Связи и поля определены в DATABASE_SCHEMA.md и DATA_MODELS.md.

## 5. Обработка форматов
Поддержать CSV/XLSX/XLS/DOCX/PDF/JPG/JPEG/PNG/TIFF в пределах лимитов. Для PDF и изображений — локальный OCR с русским/английским; для цифрового PDF сначала нативный текст. Старый DOC — честное сообщение о неподдержке. Каждый документ получает status, checksum, source provenance и immutable original.

## 6. Матчинг
Ранжирование кандидатов по exact supplier SKU, GTIN/EAN, бренд/модель, нормализованным токенам названия, атрибутам и единице/упаковке. Конфликт упаковки — сильный штраф/блок. Сохранять причины каждого score; пользователь подтверждает/отклоняет. Один SKU не означает универсальную эквивалентность между поставщиками.

## 7. Полная стоимость
Поддерживать цену за исходную упаковку, скидку, количество/кратность, валюту, доставку, страхование, налог/НДС, пошлины и другие расходы как отдельные компоненты. Формула зависит от выбранного сценария; настройки и источник фиксируются. Результат — total и unit cost на базовую единицу, валюта расчёта, округление, дата курса и предупреждения. Не предполагать налоговую возмещаемость и не подставлять юридические ставки автоматически.

## 8. API и безопасность
Контракт REST `/api/v1`; OpenAPI генерируется; идемпотентные операции используют idempotency key. Подробнее API_CONTRACTS.md. Локальный процесс привязан к loopback; данные в логе редактируются; cloud AI выключен по умолчанию.

## 9. Наблюдаемость
Локальная диагностика статусов, pipeline version, длительности и безопасных кодов ошибок. Отправка телеметрии — отдельная настройка. Correlation ID для каждой операции.

## 10. Ограничения
МVP не делает заказ поставщику, оплату, складской учёт, юридическое заключение, автоматический таможенный расчёт или скрытую загрузку документов в AI. Решения о поддержке юрисдикций и нормативных ставках требуют отдельного review.
